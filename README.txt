САПЁР — инструкция запуска

Вариант 1 (самый простой):
1. Откройте файл minesweeper.html двойным щелчком.
2. Игра запускается в браузере. CSS и JavaScript уже встроены в файл.

Вариант 2 (проект из трёх файлов):
1. Полностью распакуйте архив в отдельную папку.
2. Не перемещайте index.html отдельно от style.css и script.js.
3. Откройте index.html в браузере.

Файлы:
- index.html — разметка страницы
- style.css — стили и адаптация под мобильные экраны
- script.js — игровая логика и локальные рекорды

Рекорды хранятся в localStorage текущего браузера. Внешний шрифт загружается из Google Fonts, но игра работает и без него.
